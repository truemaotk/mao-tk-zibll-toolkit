# 数据迁移 · 友情链接

状态：Toolkit 1.16.1，友情链接本地封板，尚未部署或发布。文章和商品迁移另行开发验收。

rc.2 补齐标题区到表单的间距（桌面 18px、手机 16px）；指定链接折叠热区收紧到至少 48px，文字与搜索框左对齐，展开后保留 10px 间距。其余继承现有 Toolkit 控件与动效。

## 后台入口与交互

进入 **Mao TK Toolkit → 数据迁移**。工作台“数据迁移”组有独立的“友情链接”模块开关；新安装／升级缺省启用仅表示管理员可创建任务，不会自动迁移任何内容。已有其他模块的开关保持原值。

- 三个页签：导出链接、导入链接、任务记录。支持方向键、Home、End 和 Tab 操作。
- 复用现有蓝色控件、6px 控件圆角、8px 面板圆角、右向箭头与 380ms 折叠动效。迁移页面始终跟随系统减少动态效果设置，不显示动效选择条，不改变其他页面已存的偏好。
- 字段使用真实 select。支持的桌面浏览器使用 Toolkit 已有下拉外观；旧浏览器／触屏保留原生选择菜单。
- 预检与结果每页 20 条。最近任务显示当前账号的最新 20 个，不混入其他管理员的记录。
- 需要 JavaScript 才能迁移；禁用 JS 时明确提示，不执行导入。模块关闭仍可查看已有任务，创建与执行操作被后台拒绝。

## 导出

1. 选择全部／某个原生链接分类，以及公开／私密／全部。
2. 如只导出特定链接，展开“指定链接”，搜索并多选。选择与上方分类、可见性条件取交集；未选择时导出筛选范围。
3. 默认包含本地上传目录中的 LOGO 原文件；外部 LOGO 默认仅保留图片网址。
4. 需要把外部 LOGO 带走时，单独勾选“尝试下载外部 LOGO”，会真实请求对应图片地址。HTTP 请求采用 WordPress 安全远程读取接口，有大小和超时限制。
5. 创建任务，核对预览，再点“确认并开始”。完成后下载 ZIP 和报告。

失败项单独列出，可以重试。存在失败时，下载按钮明确标为“下载成功部分 ZIP”，文件名含 `partial`；不把部分结果描述为完整成功。

保留名称、完整网址与推荐参数、说明、备注、RSS、打开方式、rel、评分、所属账号登录名、原生分类与 `link_visible` 私密状态。链接匹配区分原始网址大小写与百分号编码，不清理推荐参数。WordPress 将 `&` 保存成 HTML 实体时按同一网址处理。

站点账号的可见角色、账号单独允许／禁止规则不在迁移范围。链接原生私密标记不会因 Toolkit 的前台显示过滤器而漏导。

## 导入

1. 在目标站上传 ZIP，选择“跳过已有链接”（默认）或“更新已有链接，并备份原记录”。
2. 点击“上传并预检”。这一步仅保存私有任务文件，**不创建链接、分类或媒体附件**。
3. 检查新增、跳过、更新和冲突列表，再确认执行。
4. 每次请求处理一条记录。可以暂停、关闭页面，之后在任务记录打开并继续。
5. 完成后核对成功／跳过／失败数量，下载报告；只重试失败项。

匹配规则为完整链接网址。包内同网址重复或目标站同网址多条记录时，不猜测应覆盖哪一条，显示冲突。预检之后的人工修改会再次核对，存在变化就停止对应项目，需重新预检。

同登录名且属于当前站点的账号可以恢复为原所有者，否则归当前执行账号。分类按 slug（有值时）或名称匹配，不覆盖目标站已有分类说明；有父级冲突就停止对应项目。空分类不会自动换成默认分类。

LOGO 以内容 SHA-256 去重。新媒体恢复标题、说明、描述和 ALT；已存在同内容媒体时直接复用，不改其元数据。导入过程不会自行抓取外部图片。媒体写入与链接写入不是数据库整体事务，失败后已创建的媒体／分类可能保留，重试会尽量复用；不自动删除媒体。

任务写入日志覆盖“链接已新增但任务未确认”的中断窗口，确认字段完全吻合后再恢复，不重复新增；人工修改不同则报冲突。任务版本与互斥锁防止同一迁移请求重复处理，这不承诺与第三方插件的并发写入形成全站事务。

## 包格式与旧格式

新格式 ZIP：

```text
manifest.json
images/<sha256>.<png|jpg|webp|gif|ico>
```

`manifest.json` 顶层字段：`format: "maotk-links"`、`version: 1`、`source`、`created_at`、`toolkit`、`links`、`categories`、`assets`。链接使用来源 `key` 引用分类与 LOGO；资源记录包含真实图片内容的 `sha256` 及元数据。输出 ZIP 另给 SHA-256 校验值。

支持用户提供旧导出器的 `links-export.zip`：根目录 `manifest.json` 是链接数组，图片在 `images/` 中，字段含 `name/url/desc/notes/target/rss/visible/rating/cats/image_orig/file`。旧 `subdir` 被忽略，不作为写入路径。旧包没有原始校验值与来源站点，界面会明确提示。

未知版本拒绝。读取 ZIP 内已验证的清单与图片字节，不使用 `extractTo()`，不执行包内 PHP、JS 或其他文件。

## 限制

| 项目 | 上限或行为 |
| --- | --- |
| 单次链接 | 1,000 条；更多按分类分批，指定列表只显示前 1,000 条 |
| ZIP / 展开总量 | 32 MiB / 64 MiB，仍受 PHP 上传限制影响 |
| 清单 / 单张 LOGO | 8 MiB / 2 MiB |
| LOGO 格式 | PNG、JPEG、WebP、GIF、可识别 ICO；不导入 SVG、BMP、可执行文件 |
| 图片像素 | 每边不超过 12,000，总像素不超过 4,000 万 |
| 原生数据库字段 | 名称、网址、图片网址、RSS、说明等按 WordPress 原生长度检查，超长拒绝，不静默截断 |
| 包有效期 | 创建后 24 小时；过期即禁止执行和下载 |
| 当前账号有效任务 | 最多 100 个；历史列表显示最新 20 个 |

`_self`、`_none` 按 WordPress 原生同窗口方式保存为空值；原生不支持的 `_parent` 会报错，需先修正源数据。

## 临时存储、权限与清理

页面需要 `manage_options`，执行还需要 `manage_links`，带 LOGO 的导入需要 `upload_files`。每个写请求与下载检查 nonce 和任务所有者；另一个管理员也不能下载你的任务包。没有未登录 AJAX 接口。

默认使用 WordPress 临时目录。如果实际目录位于网站公开目录中或不可写，将停止创建任务。可在服务器已有站外私有目录下，于 `wp-config.php` 定义：

```php
define('MAO_TK_TOOLKIT_MIGRATION_TEMP', '/srv/private/maotk-migrations');
```

请替换为已存在且对 PHP 可写、位于 `ABSPATH`、`WP_CONTENT_DIR`、插件目录与当前站点 DOCUMENT_ROOT 之外的路径。插件不自动创建服务器级目录，不修改服务器权限。

工作文件位于该目录下的独立站点哈希／随机任务目录，不放入公开 uploads。下载走已登录后台，并设置 private/no-store。目录创建权限请求 0700，仍受服务器运行环境影响；不要把父目录映射成公开静态目录。

包文件采用惰性清理：下次当前账号创建任务、读取任务记录或访问过期任务时清理过期文件。最新 20 个可保留结果元数据，之外的过期任务连元数据一起清理。没有后台定时器，因此不保证恰好满 24 小时就从磁盘删除。有效的较旧任务继续索引，避免文件丢失清理入口。

选项前缀：`mao_tk_migration_job_`、`mao_tk_migration_map_`、`mao_tk_migration_lock_`；当前用户索引 `mao_tk_migration_jobs`；媒体内容哈希 `_mao_tk_migration_sha256`。任务与映射不自动加载。停用模块／插件保留已迁入的链接、媒体和配置，不自动删除任何业务数据。

覆盖前备份在任务报告 `before_update` 中，包含旧字段和分类 ID。**目前没有一键撤销**；恢复需要先核对迁移之后的人工修改，不可直接整站覆盖。任务报告也有有效期，请及时另存。
