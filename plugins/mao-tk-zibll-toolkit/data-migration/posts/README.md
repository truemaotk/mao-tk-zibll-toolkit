# 文章导入／导出

版本：Toolkit 1.17.0-rc.1，本地验收版。友情链接采用独立封板基线，文章任务、数据格式和资源均单独管理。

## 入口与默认行为

进入 **Mao TK Toolkit → 文章导入／导出**，或在工作台“数据迁移”组打开文章模块。

- 三个页签：导出文章、导入文章、任务记录。
- 管理端沿用既有配色、圆角、真实下拉选择器、间距和折叠动效。
- 迁移页不显示动效偏好控制条，始终跟随系统减少动态效果设置；浏览器无 Web Animations API 时直接切换，功能仍可用。
- 页面和异步操作检查 ZIP 扩展、WordPress HTML 接口、站外临时目录、角色权限和模块状态。需要 WordPress 6.2 或更新版本的 `WP_HTML_Tag_Processor`；不影响其它模块原有最低版本。
- 新模块默认可用仅表示管理员可以创建任务，**不会自动执行导入**。

## 导出范围

可以按文章分类、状态、发布日期起止筛选，或填写逗号／空格分隔的文章 ID。条件取交集；每包最多 100 篇，超过时按日期、分类或 ID 分批。

默认包含本地正文图片、特色图和文章扩展字段。可保留：

- 标题、正文、摘要、原生 Gutenberg 区块和原始代码。
- 别名、状态、发布时间及修改时间、评论／引用开关、密码、文章形式、置顶标记、作者登录名。
- 分类父子关系与标签；原生图片附件编号、媒体地址、特色图。
- 普通标量／数组扩展字段，包括 Rank Math SEO 和常见子比文章配置。

临时编辑锁、编辑人、旧别名、缩略图内部 ID、迁移标记、oEmbed 缓存等不直接复制。特色图采用明确的图片映射，不把旧附件 ID 原样写入。

图片从本地 uploads 中读取原文件，不在本模块转 WebP 或重新压缩。WordPress 入库仍可能按站点原规则生成缩略图／缩放副本，原文件保留；复用前检查实际原文件哈希。共享图片只打包一次。

外部图片、下载文件、百度网盘和推荐链接保留原地址，不自动下载外部资源。取消图片打包时保留正文中的原图网址，目标站的特色图需要重新选择。

## 导入流程

1. 选择浏览器上传或私有服务器收件目录。
2. 新格式自动读取来源；旧 `posts-N.zip` 需填写旧站完整网址，以免不同站点相同原 ID 混淆。
3. 默认“跳过已有文章”，并“全部存为草稿”。需要时主动选择覆盖和保持原状态；后者可能立即发布。
4. 上传并预检，核对新增／跳过／更新／冲突。预检只写入私有任务文件，不新增文章、分类、标签或媒体。
5. 确认执行后逐张处理图片，再逐篇写入文章，最后核对已知图片与本批文章关联。进度条与阶段同步，不在关联核对结束前显示完成。
6. 可以暂停或关闭页面；从任务记录恢复。每页预检／结果 20 条；当前账号历史显示最新 20 个。
7. 完成后下载报告与原文备份；只重试失败项。新包上传期间会收起旧任务并禁用旧操作，避免误启动其它任务。

重复判定优先来源站点＋原 ID，再查精确文章别名，不按标题合并。目标站重复、包内重复或回收站冲突明确报错。预检之后的人工作品修改不会被强行覆盖，需重新预检。

作者按登录名映射到当前站点已有用户，不创建账号；没有匹配用户时归当前执行账号。分类按 slug／名称和父级匹配，不覆盖目标站已有分类说明。

## 图片与组件引用

仅替换已识别的真实引用：HTML 媒体属性、图片 srcset、已知背景图、`wp-image-ID`，以及原生 image／gallery／cover／media-text 的图片属性。原始代码、无关 JSON 数字和未知区块的 ID 不做统一替换。

本批内已迁入／已存在文章可映射真实文章链接及 `[postsbox id="…"]`／`ids`／`post_id` 中的已知引用。未知子比区块、第三方扩展字段中的商品、付费、下载配置或关联 ID 保留原值，必须在目标站核对；不能把这些引用的保留等同于相应业务已迁移。

订单、已购买权益、用户账号／角色／权限、评论、修订历史、页面、商品、站点设置及下载文件实体不在本版范围。没有修改主题文件或自动插入正文 CSS／JS。

## 备份与失败处理

覆盖目标文章前保存旧原文字段、扩展字段、分类／标签、特色图和置顶等状态，随报告 `before_update` 下载。目前没有一键整站回滚，恢复前先核对迁移之后的修改。

这是可恢复的分阶段迁移，**不是跨 WordPress、媒体文件与第三方 hook 的整体事务**。失败后已创建媒体／分类可能保留，模块不自动删除它们。重复请求用版本号和任务锁避免重放；原生文章写入中断后优先根据任务标记和已保存字段恢复，人工改动不同则拒绝覆盖。进程在极窄的原生数据库写入／任务标记窗口被终止，仍可能需要人工核对，不保证任意断电情况零残留。

任务互斥锁在异常终止后可于 2 分钟后恢复；超时会停发请求，要求刷新核对。记录每个失败项目，不把“执行结束”当成“全部成功”。导出含失败项时 ZIP 文件名和按钮明确标为部分结果。

## 文件与服务器收件目录

新包是 `manifest.json` ＋ `media/<sha256>.<ext>`，格式 `maotk-posts`、版本 1。清单包含来源、文章、分类标签、资源及 URL／附件 ID 映射。

兼容旧包的 `posts/terms/images/urlmap/attmap` 清单及 `images/年/月/文件`。旧包没有原始校验值，模块验证真实图片后再导入；旧路径不参与任意文件写入。不支持脱离图片文件的 JSON 单清单方式，也不会从任意服务器目录或旧站自动补抓图片。

私有服务器收件目录在本模块页面显示，为站外任务根目录的 `inbox` 子目录。通过服务器文件管理器自行放入 ZIP，再刷新选择；最多显示 100 个 ZIP，不接受手填任意路径或符号链接。

| 项目 | 限制 |
| --- | --- |
| 每包文章 | 100 篇 |
| ZIP / 展开总量 | 256 MiB / 512 MiB；浏览器上传另受 PHP 上限影响 |
| 清单 / 正文或单字段 | 16 MiB / 2 MiB |
| 单图 / 图片总量 | 8 MiB / 导出最多 200 MiB |
| 支持位图 | PNG、JPEG、WebP、GIF、AVIF、可识别 ICO |
| 像素 | 每边不超过 12,000，总量不超过 4,000 万 |
| 任务与备份文件 | 每任务最大 64 MiB JSON，图片单独存放 |
| 任务有效期 | 24 小时；到期禁止执行和下载 |
| 当前账号任务 | 最多 100 个有效任务，历史显示最新 20 个 |

媒体缩略图生成取决于站点 GD／Imagick、格式支持与内存配置。超过 PHP 内存或请求时限时应缩小批次、检查环境并恢复；服务器收件方式不绕过这些运行限制。

任务正文和原文备份保存在站外私有 `task.json`，通过临时文件替换保存；数据库仅保留小型任务摘要，历史不加载所有文章正文。到期后在下一次任务／历史访问时清理；没有定时器保证恰好在第 24 小时物理删除。请及时另存备份。

临时根目录复用 `MAO_TK_TOOLKIT_MIGRATION_TEMP` 配置并使用独立子目录；必须位于网站公开目录之外。下载检查当前账号、管理权限和 nonce，使用 private/no-store 响应。停用保留业务数据。

## 开发接口

- 模块：`data-migration-posts`；页面：`mao-tk-toolkit-posts-migration`。
- PHP：`inc/post-migration/`；页面：`inc/views/migration-posts.php`；独立资源：`assets/post-migration/`。
- AJAX：`wp_ajax_mao_tk_toolkit_posts_migration`；下载：`admin_post_mao_tk_toolkit_posts_migration_download`。
- 权限：`manage_options` ＋ `edit_others_posts`；完整 HTML 导入需 `unfiltered_html`；新媒体需 `upload_files`；保持发布需 `publish_posts`。
- 选项：`mao_tk_post_migration_job_`、`mao_tk_post_migration_lock_`；用户索引 `mao_tk_post_migration_jobs`。
- 原文来源／任务标记：`_mao_tk_post_migration_origin`、`_mao_tk_post_migration_write`；媒体哈希 `_mao_tk_post_migration_sha256`。

所有资源仅在自己的后台页面加载，无前台资源。来源包只解析 JSON 和已验证的位图，不执行包内代码，不用 `extractTo()`，不反序列化来源包中的 PHP 对象。

## 验证边界

隔离 WordPress 7.1.4、PHP 8.5.12、SQLite 集成、Chrome 桌面及 390px 布局：65 项文章流程检查、19 项浏览器检查通过。另有友情链接 16 项浏览器回归、共享后台／动效／加载／提示框编辑器测试。缺少 ZIP 扩展时两个迁移模块均能识别并停止操作。

本地主题仅用于依赖识别，不是真实子比源码。MySQL/MariaDB、真实子比文章组件、缓存和第三方业务扩展仍需目标测试站验收；本版尚未部署、推送或更新博客教程。
