# 配置导入&导出

版本：1.20.0-rc.1。本地候选版，未部署或推送。

后台入口：**Mao TK Toolkit → 配置导入&导出**。这是管理工具，不依赖前台模块开关，方便新安装先恢复设置。

## 使用流程

1. 原站选择需要的配置，默认包含本地自定义图片，点击“导出配置”，再下载 JSON。
2. 新站安装相同或更新版本 Toolkit，进入该页上传 JSON 并预检。此步骤不覆盖设置或写入媒体。
3. 核对分类、缺失图片或身份不匹配的提示，勾选需要恢复的分类。模块开关默认不勾选，避免意外启用维护页、邮件外观等功能。
4. 勾选覆盖确认后导入。原有配置先保存私有快照；刷新对应设置页查看结果。
5. 需要撤销时从最近记录点击“恢复此任务前配置”。导入后若该配置又被修改，恢复会停止，不强行覆盖新修改。

只有 `manage_options` 用户可操作，所有写入口检查 POST 和 nonce。记录、下载与恢复只属于创建任务的账号。

## 范围

支持 11 类配置，存储位置固定为 10 个 Toolkit 自有 option，不按前缀扫描数据库：

- 已知模块开关；正文提示框配色与提供者设置（二者共享 Toolkit 管理器 option，但分开选择）。
- 文章顶部信息、时效提示。
- 案例展示的外观、分类和案例库。
- 私密链接的角色与账号例外规则。
- 维护页、预设头像背景、订单查询页面、404 公益页面。
- 系统邮件通用设置、各类文案和独立覆盖。

不含文章、商品、友情链接记录、订单、实际支付或下载权益、用户账号及密码、SMTP 密钥、子比全局设置、主题文件或其他插件。案例页面的模板与分类选择属于页面本身，不在配置备份内；新站需创建页面后选择模板、分类。

## 图片和账号

本地自定义 PNG、JPG、WebP、GIF 和安全纯图形 SVG 可附在 JSON 内，单文件 5 MiB，总图片 24 MiB，最多 400 个不同文件；配置包最大 32 MiB，仍受服务器上传上限约束。超限时按分类分别导出。

不重新压缩、缩放或转换图片。媒体编号和图片 URL 会映射到目标站新记录，同内容图片复用；新附件保留原像素、标题及 ALT，不生成压缩副本。SVG 使用现有纯图形校验器规范化；原文件不修改。外部图片保留地址，不自动联网抓取。只迁移配置所引用的图片，不复制整个媒体库。

不含图片的备份只在目标站已有内容匹配文件时恢复图片引用；否则预检明确阻止对应分类，不直接套旧媒体 ID。

账号例外规则以用户名及邮箱 SHA-256 摘要核对目标身份，不按数字用户 ID 套用；不匹配或缺少角色时阻止这一分类，其他分类仍可选择。不创建用户或更改 WordPress 角色权限。

## 保护和恢复

- 格式 `maotk-toolkit-settings`，schema 1。只接受 JSON，绝不执行 PHP 或反序列化上传的对象。
- SHA-256 用于检查损坏，不是数字签名。即使文件校验正确，也会逐分类验证字段、变量、图片及来源引用。
- 不接受新于当前插件版本的备份、未知配置分类或未知模块。
- 预检记录所选配置的原状态；执行时重新核对，发现其他窗口修改便停止。
- 导入前保存原 option 快照和写入计划，逐项比较后写入。中途失败会尝试还原已写入项；并发新修改不被强行覆盖。
- 同一任务重复提交不会重复导入。请求中断时可在 15 分钟后恢复过期锁，再使用任务内快照恢复已写入项。
- 新导入图片在撤销或失败后保留，以免误删正在被使用的媒体；原文件和原媒体从不删除。
- 配置文件和快照放在网站目录外的私有临时位置，下载需登录、权限、nonce 和任务归属验证。必要时沿用 `MAO_TK_TOOLKIT_MIGRATION_TEMP` 指定站外可写目录，不放公开 uploads。
- 每个账号最多保留 10 条记录，文件在 7 天内可下载；超过记录上限的旧任务和私有文件会清理。请自行下载长期备份。

“恢复前快照”是当前任务的原始配置核对与撤销材料，不是跨站导入包。跨站请使用“导出配置”生成的 JSON。备份可能包含内部链接、账号身份摘要、联系文案和案例，请勿放入公开仓库或网站下载区。

## 开发位置

- 服务代码：`inc/config-backup/`。
- 后台：`inc/views/config-backup.php`、`assets/config-backup/`，只在本页加载。
- AJAX：`mao_tk_toolkit_config_backup`。
- 受保护下载：`mao_tk_toolkit_config_download`。
- 记录 option 前缀：`mao_tk_toolkit_config_job_`；账号索引 meta：`mao_tk_toolkit_config_jobs`。
- 图片去重 meta：`_mao_tk_config_asset_sha256`。

本工具不导入旧的浏览器动效偏好。全插件折叠和骨架屏现在只跟随 `prefers-reduced-motion`；不显示选择栏，不读取或改写原 localStorage 值。
