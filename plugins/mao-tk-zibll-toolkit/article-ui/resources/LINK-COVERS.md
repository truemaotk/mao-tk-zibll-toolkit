# 链接浮层封面：已核对事实与后续能力

2026-10-31。本文件明确区分当前能力和用户期待的自动封面。

## 当前已经确认

- 宿主源码：E:/zibll/plugins/mao-tk-zibll-toolkit/assets/article-ui/article-ui.js，show函数只读取data-link-preview-image，再将其赋给浮层图片。
- 宿主说明：E:/zibll/plugins/mao-tk-zibll-toolkit/article-ui/README.md第24行，明确说明只使用配置图片，不爬取页面或调用截图服务。
- 当前组件支持previewTitle和previewImage；后者为空时显示文字浮层。
- 此前页面截图是明确指定的示例图片，不是自动提取的网页封面。本版没有继续自动填入那些截图。
- v1.1.0只复用现有链接组件，不包含自动封面抓取或线上插件升级。

## 用户期待的自动封面契约，尚未实现

1. 站内文章优先读取真实特色图。
2. 站外页面读取其声明的分享封面，例如og:image，其次合适的替代元数据。
3. 由插件服务端读取和缓存元数据，按WordPress安全远程请求规则处理公开页面；前端不直接跨站读取HTML。
4. 无可用封面或读取失败时回退纯文字，不保留空图片区域，不伪造UI截图。
5. 支持明确的手动封面覆盖，并记录图片来源、抓取时间与缓存状态。
6. 打开和复制仍使用原完整目标地址，封面处理不得替换aff、ref、promoteWay或原生golink。

该能力需要修改宿主链接模块的服务端与数据接口；当前独立样板不能证明已具备。后续实施时先核对实际插件结构和授权范围，再实现与验收。
