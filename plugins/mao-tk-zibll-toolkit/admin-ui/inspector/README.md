## 固定视觉与交互

- 标题是设置行自身的整行热区，至少48px高；底色贴齐分隔线，取消内部悬停圆角色块。面板标题、折叠标题与表单字段共用22px水平基线。
- 悬停底色`#f6f7f9`，文字`#20314b`，按下`#eef1f5`。120ms颜色过渡，不位移、不放大、不改字重、不增加浮起阴影。
- 箭头沿用现有本地细线右箭头，展开绕中心旋转90°朝下；380ms实测高度引擎继续负责展开、收起、快速反向、表单定位和重绘。避免叠加原生details的第二层尺寸／透明度过渡。
- 键盘保留单层1px内侧焦点线。当前浏览器动效偏好为on时允许完整过渡，off时关闭；system尊重系统减少动态效果。
- 案例列表、右侧设置、画布及管理端图片弹窗的滚动槽固定占位。WebKit支持时宽高8px，滑块默认4px、悬停6px；两端按钮隐藏，悬停不改变槽宽。Firefox等环境使用系统thin，不能保证与WebKit像素外观完全相同。
- 滚动条使用auto原生颜色／宽度属性后再定制WebKit伪元素，避免非auto的标准scrollbar-color优先覆盖细款外观。
