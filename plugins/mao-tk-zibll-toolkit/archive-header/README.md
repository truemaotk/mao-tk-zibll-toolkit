# 归档页顶部

打开 WordPress 后台「Mao TK Toolkit → 归档页顶部」。新模块默认关闭。开启后，三类普通归档页共用显示设置。默认隐藏封面、显示正文描述。关闭「显示封面图」后，标题栏不输出封面图片元素。标题下划线跟随文字，右侧搜索沿用子比弹窗，并限定在当前分类、标签或专题。

「显示正文描述」控制顶部可见文案。标题、描述、封面数据和索引设置仍由原有分类资料、主题与 SEO 插件管理。Google 是否收录及实际显示哪段摘要由搜索引擎决定。

模块基于已核对的子比 9.2 普通归档模板，使用原有排序、列表、分页、分类权限和小工具入口。文档模式分类、另有自定义模板的页面以及未匹配的主题版本沿用现有模板。切回原版可关闭模块。
