# 安装与跨聊天复用

本包是本地写作技能，不是WordPress插件。技能保存编排和调用规则；网站实际显示依赖Zibll、Mao TK Toolkit及对应模块。当前样式基线1.5.7，其他主题不保证兼容。

解压后保持整个 `maotk-toolkit-articles/`：SKILL.md、agents、references、assets、scripts在同一层级。随附区块模板、引用文档和源码检查器缺失会影响使用。

先核对当前Codex能发现的技能目录。当前官方说明支持项目 `.agents/skills/` 与个人 `~/.agents/skills/`；部分既有桌面安装（包括本技能原机器）已从 `~/.codex/skills/` 识别。保留一个实际可识别的副本，别在两个目录重复安装同名技能。用“请检查本机可识别的技能目录，再安装这个下载包”让接手者核对，不为技能安装擅自改全局配置。发现更新未刷新时重新打开会话，必要时重启客户端。

新聊天明确写：`使用 $maotk-toolkit-articles 写一篇关于……的文章。` 并提供目标站点、读者、素材和交付方式。已明确授权直接发布时沿用授权；否则交付草稿。本技能不会自动获得WordPress账号、上传或发布能力，不在包内保存密码、令牌或Cookie。

若未出现在技能列表，可提供已解压的SKILL.md实际绝对路径，要求读取本文件和相关引用后工作；这只是明确读取工作规则，不等于客户端已经完成自动发现。

换到新站点时核对主题、Toolkit版本、模块开关、提示框提供者，并替换文章、附件、图片和商品编号。示例站链接只能作为结构参考。源码检查器只读本地文件，不登录网站、不上传、不修改主题；它不能替代前台、窄屏、权限与保存回读验证。

参考：OpenAI《Build skills》https://learn.chatgpt.com/docs/build-skills （2026-10-30核对）。安装路径与客户端界面可能变化，以当前版本实际发现结果为准。
