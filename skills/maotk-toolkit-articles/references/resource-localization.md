# 迁移资源本地化与发布验收

迁移旧站文章时读取。图片、原封面、可取得的下载文件保存到目标新站或用户明确指定的可控存储，再替换文章引用；保留原来的免费、付费、会员和隐藏规则。已有合格的新站文件直接复用，不重复上传。

## 先盘点原文与业务

备份原区块源码和相关元数据，记录原网址到新文章的对应关系。清点正文、折叠区和隐藏区中的图片、srcset、大图链接、视频封面、下载图标、链接预览图，以及特色图片、外链特色图、单篇封面和幻灯片字段。公开页面会隐藏付费内容，不能据此认定资源已经清完。

记录付费模式、普通价格、各会员价格、购买权限、时效及隐藏块的范围。迁移原生业务结构和设置，不以静态卡片代替权限。旧站附件编号只在原站有效，新站必须使用实际上传或复用的附件编号；不能把旧的 data-download-file 或商品 ID 直接套到新站。

## 取得文件并迁到目标站

维护一份资源对应表：原 URL／原附件、用途、新文件名、字节数、SHA-256、图片宽高和格式、新附件 ID／URL、使用位置和核验结果。下载包、资料、视频教程分别命名，不根据网盘 URL 猜内容。

- 图片、封面和图标按 [图片流程](images-covers-and-seo.md) 处理。旧封面保持已确认的布局；已合格的 WebP 不重复压缩。截图与原稿分别保留，敏感信息按本次授权处理，不公开凭据副本。
- 原下载入口失效时，先核对原始媒体库、真实文件和已有备份。镜像可能保留文章而漏掉 PDF、ZIP 或视频附件；同号附件不存在不等于原始文件已删除。不要仅替换域名、猜文件路径，或用相似文件冒充原件。
- 文件可取得后，上传目标站并填写真实标题、ALT和必要说明；同时更新区块 JSON／HTML、图片大图地址、srcset、预览图和封面覆盖字段中的相关引用。原生文件下载继续绑定真实附件，原付费内容仍放在相同权限范围。
- 用文件类型对应的本地图标，不把通用叠页图标误当成 PDF 专用图标。不添加图标 CDN或为图标改主题；纯静态 SVG 可保留合适的矢量格式。
- 百度网盘分享页、官方文档和推广链接与站内附件分开处理。保留合法外部入口的完整参数、提取码和用途；它们不因“本地化”而全部改成新站网址。未取得视频字节时，说明仍由网盘提供，不能声称已站内托管。
- 来源失效、文件缺失、访问被阻止或权限不明时，记录具体缺项，不绕过限制、不伪造验证。说明会影响什么；删除或更换重要原资源依本次授权执行，已获明确授权不重复询问。移除文章入口不等于永久删除历史媒体。

旧站阅读链接也需分类：已迁移的教程改到对应新文章；尚未迁移的教程列入待办，不能猜新 URL。需要移除、改为官方说明或改为正文内已有内容时，按任务授权处理，并保持链接文字与新目标一致。推广入口不擅自换成无推广参数的官网首页。

## 发布前检查

先跑源码检查器，再对本次来源域名检查旧引用；可附加封面等元数据文件：

```text
python <技能目录>/scripts/check_article.py article.blocks.html
python <技能目录>/scripts/check_resource_localization.py article.blocks.html --old-host m.maotk.com --old-host micdu.com --old-host disk.aucau.com --metadata article-media.json
```

资源检查器只读本地文本，发现旧域名引用时返回非零状态，区分资源、下载和阅读链接线索。每一项需核对并处理或记录已授权的例外；不要自动全局替换域名。它不连接网站，不证明文件已经上传、HTTP 成功或权限正确，也不能代替检查隐藏区和原生后台字段。

## 上线后核验

1. 保存后刷新编辑器回读，核对实际源码、真实附件 ID 与上述业务设置；不要覆盖别人刚更新的正文。
2. 在匿名正式页面检查免费内容、原生下载与图片查看。付费目标不应出现在无权益页面的 HTML、链接目标或公开接口中；管理员可见不等于游客可见。没有实际付款时不声称付款测试通过。
3. 下载新站直链和所用原生下载按钮提供的文件，检查完整字节、格式和哈希；应与迁移原件相符。图片须有正确尺寸或比例占位、可放大，手机不溢出。遇到偶发连接失败，只针对失败项有限复查，不能把请求成功等同内容正确。
4. 检查正文和覆盖字段不再加载旧站资源，公开 head 中的封面、canonical 和原 noindex 设置正确。保留有效标题与 SEO；不为资源迁移修改主题或全局收录设置。
5. 区分“文章源码无旧引用”“资源已验证可用”“视频已播放”“整站已全部迁完”，只报告实际完成的范围。原稿、付费入口和后台备份留在私有维护目录，不打进公开 SKILL、下载包或 GitHub。
