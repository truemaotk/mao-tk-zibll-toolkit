# MaoTK 文章排版与 Toolkit 调用

把内容写清楚，并通过原生区块、短代码和组件包装调用插件。不要为每篇文章重新设计一套样式。基础组件以 Toolkit 1.5.7、子比9.1及教程31为历史基线；推荐与外部工具卡已在1.7.0接入。版本和站点开关须按当前任务核对。当前技能包版本为 1.3.0。

## 不变的边界

- **样式与交互由 Toolkit/主题提供。** 存储的文章中不写 `<style>`、`<script>`、样式表链接、`style`属性或 `onclick` 等内联事件；不插入第二套图标库、字体/CDN或初始化脚本。原生模块在渲染时生成的资源不等于作者内嵌代码，不要删除它们。
- **标题与目录保留子比原生。** 文章标题填在编辑器标题栏；正文H2优先用 `zibllblock/biaoti`，H3用原生标题块。不重复放H1，不另造装饰性编号、字号、分隔线或自建目录，不手写主题生成的 `wznav_*` ID；保留原文的实操步骤编号与顺序。
- **只保存组件结构和支持的配置。** 不从前台复制 `data-mao-tk-ui-*`、`data-mao-tk-note-visual`、ready/open/inert状态或提示框运行时CSS变量。使用区块原名与序列化，不能将前台HTML伪装成可编辑原生块。
- **保留原生业务。** 下载、隐藏/付费内容、商品、账户权限、文章联动、视频与媒体继续走子比原生功能。CSS不做鉴权，静态按钮不代替购买、下载或实际商品资料。
- **迁移资源保存到新站。** 图片、封面和可取得的下载文件使用目标站真实附件；隐藏区、封面覆盖字段及旧站阅读引用同样检查。先保留原业务权限，再验证文件和公开页；不只换域名或照搬旧附件编号。
- 不为写文章顺带改封板资源、全站配色、收录设置、主题文件或升级插件。缺少能力时说明具体缺项，用当前可用的原生呈现或交付草稿；不要在正文补CSS/JS绕过。

## 开始写之前

1. 识别目标站点与文章，先读当前正文和现有标题、下载、图片、封面、SEO、分类标签。修改已有文章先备份原始区块源码与必要元数据，避免重复章节或覆盖别人刚完成的内容。
2. 核对实际 Toolkit 版本、相关模块开关与区块提供者。连接器必须对应目标站点；能力不足再用浏览器。版本/运行情况不明时，不能把本技能的历史验收当作当前已通过。
3. 读取 [组件调用表](references/components.md)。需要原生媒体、下载或商业组件时，再读 [原生功能边界](references/native-boundaries.md)。改写或迁移旧文章时，先读 [旧文完整保留与逐项核对](references/rewriting-existing-articles.md)；迁移资源时，另读 [资源本地化与验收](references/resource-localization.md)；排查样式时，读 [基线与排查](references/baseline-and-checks.md)。
4. 涉及 Toolkit、文章 SKILL 或 Order Email Manager 的教程，读取 [项目仓库与下载更新](references/repositories-and-downloads.md)，引用对应仓库。文章已有或需要新增下载区时，本次撰写／更新都先核对当前正式发行与实际安装包，再替换过时入口；历史版本号、旧附件编号和整仓库源码 ZIP 不能当成最新安装包。

5. 本次涉及图片、封面或 SEO 时，读取 [图片、封面与 Rank Math 默认流程](references/images-covers-and-seo.md)。新文章默认生成专属封面；封面和照片优先在 towebp.io 以 Quality 80% / Size x1 转 WebP，文字密集截图优先真正无损。逐项填写并保存回读 Rank Math 字段；明确的用户要求优先。

换聊天、迁移工作区或安装下载包时，参考 [安装与复用](references/install-and-reuse.md)。技能应保持一个完整文件夹，不只粘贴SKILL.md；发现同名已安装版本时先备份再定点更新，不再装重复副本。

## 改写旧文章

**先逐项核对，再优化；默认完整保留原来的实操步骤、图片、代码、推荐和下载入口。** 重写不等于摘要，不以篇幅、视觉简洁或追求新版为由大幅删减。先建立旧项到新稿位置的对应表，再逐图阅读并核对每个点击、字段、命令与下一步；不能只数图片或只读提纲。

保留用户实际使用的软件分支、协议和操作顺序；新版差异单独补充，不擅自用另一套方案替换主线。推广链接保留完整参数与原推荐关系，不能换成无推广参数的官网首页。主流程和对应图保持可见，仅折叠补充内容。缺项与失效项明确记录，不靠猜测补齐，也不默默删除；必要删改先取得相应授权。

资源用途按原文、真实文件或用户确认命名：**视频教程、资料包、安装包、源码分别写清楚**，网盘地址本身不能证明里面是什么。同步检查标题、下载块、按钮、图注、摘要、SEO与相关引用。未实际打开或播放，不声称内容、集数、时长或可用性已验证。

## 编排文章

先按读者任务确定结构，直接说明用途、做法、结果与必要限制；短段落、一段一件事。步骤用列表，字段对照用表格，关键提醒用少量真实提示框。沿用克制的边框和层次，不用装饰卡片替代正文，也不强制每篇凑齐所有组件或状态。

普通教程以 [文章外壳](assets/article.blocks.html) 的单个根组为起点：`maotk-ui-kit mtk-article-reading`。将所需的组件片段放在组内，保持根组直属内容；不要反复嵌套同一根组。模板里的 `{{...}}` 均需替换，正文/URL/属性按各自上下文转义，ID使用真实数字。

| 需求 | 调用方式 |
| --- | --- |
| 阅读间距、图片边界、FAQ、变量复制 | 根组额外类 `mtk-article-reading`；使用组件表中的明确结构 |
| 代码或可复制文案 | `mtk-code-wrap` 包原生 `zibllblock/enlighter`；保留三个原生工具及主题语法色 |
| 链接预览与已确认的链接动效 | 普通链接自动接入预览；需要定稿下划线/文字动效时用 `mtk-link-demo` 与 `mtk-link-label` |
| TAB | `mtk-native-tabs` 包原生顶部 `.post-tab.nav-top`；只保留B极简线条式，不增加切换事件 |
| 文章卡片 | `mtk-native-postsbox` 包真实 `[postsbox post_id="…"]` |
| 正文提示 | 真实 `maotk/note`；配置只放在支持的 `maoTkNoteVisual` 字段中，不写CSS |
| 推荐与外部工具入口 | Toolkit 1.7.0+ 的 `article-ui-resources` 模块及真实项目结构，见组件表；保留原推广目标与下载用途 |

图片用原生 Image 块，保留真实原图、ALT与说明；新截图来自当前界面，不伪造 UI。上传版默认按图片流程转 WebP，原稿不覆盖、不默认缩尺寸。80% 是有损质量起点，100% 也不等于无损；需要精确保留小字时使用显式无损编码或保留 PNG 并记录例外。新文章默认生成封面，更新已有文章保留已确认封面；封面四周留足安全边距、文字简短。完整转换、封面与 SEO 字段步骤见上述参考。

提示色默认继承后台通用与类型设置，不因对比度判断自行写入单块 `light`／`dark`。只有用户明确要求某个提示独立配色时才覆盖，并说明该块以后不随后台颜色变化。后台已保存而前台不变时，先检查单块覆盖；恢复继承只清除对应颜色字段，保留位置、图标等其他配置。内部标题保持原 `div` 字段，不为装饰改成H2/H3。

代码外壳、顶栏色差和代码后正文间距由 Toolkit 提供（桌面20px、手机18px），不在文章补样式。提示词、邮件等纯文本使用原生 `raw`，真正程序代码选择正确语言；代码块主题字段留空继承子比设置，不固定语法色。换聊天可复用本技能；换到其他网站先核对 Zibll 与 Toolkit 依赖，其他主题需要另行适配，不能承诺解压即获得同样外观。

## 检查并交付

运行自带的源码检查器：

```text
python <本技能目录>/scripts/check_article.py <正文.blocks.html>
```

检查器只读文件，检查禁止内嵌资源、运行时残留、区块配对、唯一ID和必要包装。处理错误与相关警告；“未发现阅读根组”不能当作阅读样式已经接入。它不是WordPress编辑器、链接可达性、插件开关或付费权限测试。`--fragment`仅用于尚未放入根组的组件片段，不用于跳过整篇文章的包装检查。

在WordPress原生预览中检查插件实际生效，再按任务授权保存或发布；本技能本身不授权发布、覆盖网站或修改全局设置。已有明确授权时直接执行，不重复确认。至少检查所用组件、原生目录/图片查看、窄屏溢出及保存回读；复制提示不等于系统剪贴板内容已验证。

涉及图片与 SEO 时，还需核对压缩模式、原尺寸文字清晰度、特色图像、媒体 ALT、Rank Math 保存回读及公开页实际 head 输出；不擅自解除 noindex。

若最终需要上线，确认公开页而不是仅编辑器或旧缓存，并保存真实截图。交付文章链接、源码/备份位置、实际使用版本和重要未验证项；无需向读者展示实现细节。
