## Toolkit 1.24.0-rc.9 — R2 下载浏览器授权（2026-11-05）

- 汇总 rc.6–rc.8 的正文下载卡片路由修复。公开文件通过 WordPress 前台处理，文章内已保存的旧卡片在显示时迁到前台入口，适配子比的后台访问保护。
- 同一篇文章可同时提供公开文件和子比原生付费文件。公开卡片在原文发起同源 POST，直接打开复制的公开入口会回到原文。付费入口继续经过子比购买、会员及额度检查。
- WordPress 与下载 Worker 建立浏览器会话，签发绑定该会话的十分钟临时地址。复制最终地址到另一浏览器会被拒绝。同一浏览器在有效期内支持 HEAD 与 Range 续传。
- 建立会话阶段提前返回，回调再次核验原生权限后才执行子比下载计数。
- 配套 Worker 使用 v2 协议，旧 v1 接口默认返回 403。升级时先以 MAOTK_R2_ALLOW_LEGACY=1 部署 Worker，再升级插件、清文章缓存并验收，最后关闭过渡变量。回退插件前先恢复 Worker 兼容模式。
- 本地通过 WordPress 7.1.4 与 Worker 的 HTTP 联调、实际子比 9.2 下载模板契约、配置加密和上传回归，178 个 PHP 文件语法检查通过。线上免费文件验证得到同会话 200、复制到其他会话 403、Range 206，旧接口已关闭。线上测试仅请求文件前四字节，真实付费账号权益和计数仍待实际账号验收。

安装包使用本次预发布附件中的 WordPress ZIP，下载 Worker 源码作为独立附件提供。升级步骤见 [R2 下载指南](../plugins/mao-tk-zibll-toolkit/R2-DOWNLOADS.md#v2-worker-升级顺序)。
